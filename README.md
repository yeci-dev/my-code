## p5-sketch — 从拖尾到雨夜车窗

一路加东西做出来的六个版本，按顺序看：

| 文件 | 内容 |
|---|---|
| `index.html` | 黑底，鼠标拖出一道红色轨迹 |
| `v2.html` | 加上速度：手快慢决定圆的大小和亮度 |
| `v3.html` | 下雨，鼠标是一盏模糊的路灯 |
| `v4.html` | 雨滴落地溅水花、扩散涟漪，有远近纵深 |
| `v5.html` | 加上风和闪电（按 F 手动打闪） |
| `v6.html` | 换成真实照片当背景：车窗上的水珠会往下滑 |

**怎么跑**：双击任意 `.html` 就行，全部离线可用，不需要联网。

快捷键：`R` 重置，`S` 存图。
